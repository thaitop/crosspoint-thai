**Goal:** Put the Thai features and the Ledger/Today/Calendar home themes from `crosspoint-x4pro-th` onto upstream tag `2.0.0`, as a few rebase-friendly commits that build for every board.

**Architecture:** Port from the final state of `crosspoint-x4pro-th` branch `feature/calendar-theme` (called SRC below; local path `/Users/thaitop/Documents/GitHub/crosspoint-x4pro-th`). **Spec:** `docs/superpowers/specs/2026-11-07-thai-port-v2-design.md`

- Branch `thai-2.0.0` from tag `2.0.0`. Never work on `master`.
- Follow `CLAUDE.md` and `.agents/rules/`. Format with `./bin/clang-format-fix -g` only.
- **Commits need explicit owner approval.** Every "Commit" step below means: stage, show the owner the diff summary, and commit only after they approve. Never push.
- Keep every upstream theme and its stored value: Classic=0, Lyra=1, Lyra Extended=2, RoundedRaff=3, Cover Grid=4. New: Ledger=5, Today=6, Calendar=7, all under the key `uiTheme`.
- No Thai glyphs in the built-in reader fonts (NotoSans 12–18). Do not port SRC commits `50b05d8` or `576671d`, or SRC's `platformio.ini`, `.github/`, `nix/`, README or USER_GUIDE changes.
- Behavior must match SRC. No new features or redesigns.
- Flash stop rule: if any board env stops fitting its partition, stop and report numbers to the owner. Do not add per-board flags.
- Each new heap allocation needs a stated reason (see `.agents/rules/hardware-resources.md`).
- Build envs (code variants): `default slim sticky x4pro metalio_eink4 x4c papermono eego_a4 picco`. Command per env: `pio run -e <env>` (global pio: `~/.platformio/penv/bin/pio`). Record full output in a log under the scratchpad, report only the RAM/Flash summary lines.
- Host tests: `uvx cmake -S test -B build/host-test && uvx cmake --build build/host-test -j && (cd build/host-test && uvx --from cmake ctest --output-on-failure)`. If the repo's testing rule names a different runner, use that one.

## Review Focus

1. **Theme value clamping.** `CrossPointSettings.cpp:180` clamps an enum to `enumLabels().size()`, so the stored value is the list index. A board without PSRAM that hides Cover Grid by shortening the list would reset Ledger/Today/Calendar (5–7) to the default on load. Expected: Ledger/Today/Calendar persist across reboot on X3/X4 (no PSRAM). Test in Task 7.
2. **Mixed Thai and Latin in one word**, e.g. `iPhoneรุ่นใหม่` or `ก.ค.2026`. Expected: break only between Thai words or at the Thai/Latin edge allowed by `breakByteOffsets`; never inside the Latin part. Test in Task 2.
3. **A Thai run that is not in the dictionary and is wider than the line** (UI label or a long name). Expected: `wrappedText` breaks at a cluster start, never between a letter and its marks. Test in Task 4 (or Task 2 via `clusterStart` if no renderer harness exists).
4. **Thai UI text with a font that lacks Thai** (slider readout in NotoSans 18). Expected: readout falls back to the theme title font, no missing-glyph boxes. Covered by Task 5 code and owner device check.
5. **Reading log before the clock is set, and across a month change.** Expected: nothing logged without a set clock; the month array resets on a new month while the 7-day log keeps the last week. Owner device check in Task 6 (no host harness for `PersistableStore`).
