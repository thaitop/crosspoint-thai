เวอร์ชันล่าสุด —

อ่านหนังสือไทย บน e-reader ได้ถูกต้อง ทุกวรรณยุกต์

เฟิร์มแวร์ CrossPoint ฉบับภาษาไทย สำหรับ Xteink X4 Pro และ Metalio E-Ink4-Plus เสียบสาย USB แล้วกดติดตั้งจาก browser ได้เลย ไม่ต้องลงโปรแกรม

ติดตั้งเลย

ใช้เวลาประมาณ 1–2 นาที

ธีมหน้า Home ใหม่ 3 แบบ Ledger · Calendar · Today

ภาษาไทยที่อ่านแล้วไม่สะดุด

ทุกอย่างทำงานในเครื่อง ไม่ต้องใช้อินเทอร์เน็ต และใช้ได้กับฟอนต์ไทยบน SD card ด้วย

  1. การอ่าน

    สระและวรรณยุกต์อยู่ถูกที่

    วรรณยุกต์ซ้อนบนสระบนได้ถูกต้อง ยกพ้นนิคหิตของสระอำ และเลื่อนซ้ายบนพยัญชนะหางสูง ป ฝ ฟ ข้อความตัดบรรทัดระหว่างคำด้วยพจนานุกรม ไม่ตัดกลางคำ

  2. เมนู

    เมนูภาษาไทยครบทุกข้อความ

    เลือก ไทย ในการตั้งค่าภาษา ข้อความที่ยาวเกินจะตัดตามคำ และไม่แยกพยัญชนะออกจากสระหรือวรรณยุกต์

  3. หน้าจอพัก

    ปฏิทินไทยตอนพักเครื่อง

    ปี พ.ศ. ปีนักษัตร ข้างขึ้นข้างแรมพร้อมภาพดวงจันทร์ของวันนั้น และวันสำคัญที่กำลังจะมาถึง

ติดตั้งในคลิกเดียว

ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ การตั้งค่าและหนังสือในเครื่องยังอยู่ครบ

  1. เสียบสาย USB-Cต่อเครื่องกับคอมพิวเตอร์ แล้วเปิดเครื่อง
  2. กดปุ่มติดตั้งของรุ่นที่คุณมีด้านล่าง
  3. เลือกพอร์ตแล้วรอประมาณ 1–2 นาที ห้ามถอดสายระหว่างนั้น

Xteink X4 Pro

ESP32-S3 · ทดสอบบนเครื่องจริงแล้ว

ฐาน CrossPoint 2.0.0 รุ่นเสถียร เมนูมีทุกภาษาของต้นฉบับรวมถึงภาษาไทย

browser นี้ติดตั้งผ่าน USB ไม่ได้ เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ (ผ่าน https) หรืออัปเดตผ่าน SD card ด้านล่าง

flash ผ่าน USB ไม่ได้? อัปเดตผ่าน SD card
  1. ดาวน์โหลดไฟล์เฟิร์มแวร์ ไฟล์จะชื่อ firmware.bin
  2. คัดลอกไปไว้ที่ root ของ SD card แล้วใส่การ์ดกลับเข้าเครื่อง
  3. บนเครื่อง ไปที่ Settings → General → SD Card Firmware Update
ดาวน์โหลด firmware.bin

Metalio E-Ink4-Plus

ESP32-S31 · ทดสอบบนเครื่องจริงแล้ว

จอความละเอียดสูง ไอคอนและฟอนต์เมนูคมขึ้น เมนูมีภาษาไทยและอังกฤษ

browser นี้ติดตั้งผ่าน USB ไม่ได้ เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ (ผ่าน https) หรือดาวน์โหลดไฟล์จาก Releases

หลังติดตั้งเสร็จ

  1. ไปที่ Settings → General → Language แล้วเลือก ไทย
  2. ตั้งเวลาเครื่องที่ Settings → General → Clock เพื่อให้บันทึกเวลาอ่านและปฏิทินไทยทำงาน
  3. หนังสือไทยต้องใช้ฟอนต์ที่มีอักษรไทย ใส่ฟอนต์ลง SD card ตามคู่มือฟอนต์บน SD card

หน้านี้รองรับเฉพาะ X4 Pro และ E-Ink4-Plus รุ่นอื่น เช่น Xteink X3/X4 ยังต้อง build เอง

Xteink บางเครื่องล็อก USB มาจากโรงงาน ดูวิธีปลดล็อก อยากกลับไปใช้เฟิร์มแวร์เดิม ใช้ web flasher ของ CrossPoint

โปรเจกต์ open source ไม่มีส่วนเกี่ยวข้องกับ Xteink, Metalio หรือผู้ผลิตรายใด และไม่ใช่รุ่นทางการของ CrossPoint
