CrossPoint ภาษาไทย
ฟีเจอร์ ติดตั้ง GitHub

เวอร์ชันล่าสุด —

อ่านหนังสือไทย บน e-reader ได้ถูกต้อง ทุกวรรณยุกต์

เฟิร์มแวร์ CrossPoint ฉบับภาษาไทย สำหรับทุกรุ่นที่ CrossPoint รองรับ ทั้ง Xteink, Metalio, Seeed, M5Stack, EEGO และ Onyx เสียบสาย USB แล้วกดติดตั้งจาก browser ได้เลย ไม่ต้องลงโปรแกรม

ติดตั้งเลย

ใช้เวลาประมาณ 1–2 นาที

ธีมหน้า Home ใหม่ 4 แบบ Ledger · Calendar · Shelf · Today

ภาษาไทยที่อ่านแล้วไม่สะดุด

ทุกอย่างทำงานในเครื่อง ไม่ต้องใช้อินเทอร์เน็ต และใช้ได้กับฟอนต์ไทยบน SD card ด้วย

  1. การอ่าน

    สระและวรรณยุกต์อยู่ถูกที่

    วรรณยุกต์ซ้อนบนสระบนได้ถูกต้อง ยกพ้นนิคหิตของสระอำ และเลื่อนซ้ายบนพยัญชนะหางสูง ป ฝ ฟ ข้อความตัดบรรทัดระหว่างคำด้วยพจนานุกรม ไม่ตัดกลางคำ

  2. เมนู

    เมนูภาษาไทยครบทุกข้อความ

    เลือก ไทย ในการตั้งค่าภาษา ข้อความที่ยาวเกินจะตัดตามคำ และไม่แยกพยัญชนะออกจากสระหรือวรรณยุกต์

  3. หน้าจอพัก

    ปฏิทินไทยตอนพักเครื่อง

    ปี พ.ศ. ปีนักษัตร ข้างขึ้นข้างแรมพร้อมภาพดวงจันทร์ของวันนั้น และวันสำคัญที่กำลังจะมาถึง

ติดตั้งในคลิกเดียว

ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ การตั้งค่าและหนังสือในเครื่องยังอยู่ครบ

  1. เสียบสาย USB-Cต่อเครื่องกับคอมพิวเตอร์ แล้วเปิดเครื่อง
  2. เลือกเครื่องแล้วกดติดตั้งเลือกผู้ผลิต แล้วเลือกรุ่นที่ตรงกับเครื่องของคุณด้านล่าง
  3. เลือกพอร์ตแล้วรอประมาณ 1–2 นาที ห้ามถอดสายระหว่างนั้น
ผู้ผลิต
รุ่น

เลือกผู้ผลิตและรุ่นของเครื่องด้านบน แล้วปุ่มติดตั้งจะแสดงตรงนี้

Xteink X4 Pro

ESP32-S3 · 480 × 800

ฐาน CrossPoint 2.0.0 รุ่นเสถียร เมนูมีทุกภาษาของต้นฉบับรวมถึงภาษาไทย

browser นี้ติดตั้งผ่าน USB ไม่ได้ เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ (ผ่าน https) หรืออัปเดตผ่าน SD card ด้านล่าง

flash ผ่าน USB ไม่ได้? อัปเดตผ่าน SD card
  1. ใช้ได้กับเครื่องที่ลง CrossPoint ไว้แล้วเท่านั้น ดาวน์โหลดไฟล์เฟิร์มแวร์ ไฟล์จะชื่อ firmware.bin
  2. คัดลอกไปไว้ที่ root ของ SD card แล้วใส่การ์ดกลับเข้าเครื่อง
  3. บนเครื่อง ไปที่ Settings → General → SD Card Firmware Update
ดาวน์โหลด firmware.bin

Onyx Picco / BOOX Tiles

ESP32-S3 · 480 × 800

ติดตั้งเฉพาะตัวแอป ส่วน bootloader และโหมดกู้คืนของผู้ผลิตยังอยู่ครบ

browser นี้ติดตั้งผ่าน USB ไม่ได้ เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ (ผ่าน https) หรือดาวน์โหลดไฟล์จาก Releases

รุ่นนี้อัปเดตผ่าน SD card ไม่ได้ ไฟล์เฟิร์มแวร์อยู่ใน Releases

หลังติดตั้งเสร็จ

  1. ไปที่ Settings → General → Language แล้วเลือก ไทย
  2. ถ้าเครื่องมีนาฬิกา ตั้งเวลาที่ Settings → General → Clock เพื่อให้บันทึกเวลาอ่านและปฏิทินไทยทำงาน
  3. หนังสือไทยต้องใช้ฟอนต์ที่มีอักษรไทย ใส่ฟอนต์ลง SD card ตามคู่มือฟอนต์บน SD card

Xteink บางเครื่องล็อก USB มาจากโรงงาน ดูวิธีปลดล็อก

ข้อควรทราบ

  • เฟิร์มแวร์นี้แจกให้ใช้ตามสภาพ ไม่มีการรับประกันใดๆ การติดตั้งเป็นความรับผิดชอบของผู้ใช้เอง
  • ผู้พัฒนาไม่ได้มีเครื่องทุกรุ่น บางรุ่นจึงยังไม่ได้ลองบนเครื่องจริง ถ้าเจอปัญหา แจ้งได้ที่ GitHub Issues พร้อมบอกรุ่นของเครื่อง
  • ถ้าอยากกลับไปใช้เฟิร์มแวร์เดิม ใช้ web flasher ของ CrossPoint หรือโปรแกรมของผู้ผลิต

โปรเจกต์ open source ไม่มีส่วนเกี่ยวข้องกับ Xteink, Metalio, Seeed, M5Stack, EEGO, Onyx หรือผู้ผลิตรายใด และไม่ใช่รุ่นทางการของ CrossPoint
